Default Material

Surfaces do not have material definitions assigned to them in new drawings created from scratch. 
surfaces are rendered using the default global material if there is no specific material assigned.
the default rendered color is based on the AutoCAD Color Index (ACI) color of the AutoCAD object (usually set BYLAYER).

https://www.tutorial-autocad.com/assigning-materials-in-models


The root owner of most objects appearing in the OBJECTS section is the named object dictionary, which is,
